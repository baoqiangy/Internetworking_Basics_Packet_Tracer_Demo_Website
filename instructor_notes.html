Preparation checklist

  1. Use the same Packet Tracer version and device models that will be used in class.
  2. Save three files for each major demo: START, FAULTED, and COMPLETE.
  3. Increase application zoom and terminal font size before class.
  4. Keep commands in a plain-text file for emergency copy/paste, but type the important commands slowly while explaining them.
  5. Use Simulation Mode selectively; too many protocols in the event list can obscure the lesson.

Suggested narration pattern

For every configuration action, state: the requirement, the device/layer responsible, the configuration, and the verification evidence. During troubleshooting, ask for predictions before revealing the next command.

Device compatibility

Packet Tracer IOS syntax and feature support vary by model and release. Common substitutions include GigabitEthernet versus FastEthernet names, router-on-a-stick versus multilayer switching, and local AAA when centralized AAA is unavailable.

Prepared as an instructor demonstration guide. Adjust interface names to the Packet Tracer device model in use.
