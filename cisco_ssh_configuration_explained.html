Cisco IOS SSH Configuration: Explained

These commands configure a local administrator account and generate an RSA key pair on a Cisco router or switch, usually as preparation for enabling SSH (Secure Shell) for secure remote management.

1. Explanation of each command

Command 1: configure terminal

configure terminal
  • Enters global configuration mode from privileged EXEC mode.
  • Allows changes to the device configuration.
  • The prompt changes from Router# to Router(config)#.

Command 2: ip domain-name northstar.com

ip domain-name northstar.com
  • Configures the device's domain name as northstar.com.
  • The domain name and hostname form a fully qualified domain name (FQDN).
  • On Cisco IOS, hostname and domain name are conventionally used when generating RSA keys for SSH.

For a device with hostname SW1, the FQDN is:

SW1.northstar.com
Important: The domain does not need to be publicly registered for a classroom SSH lab. The command does not automatically register the device in DNS.

Command 3: username netadmin privilege 15 secret N0rthstar-Admin11!

username netadmin privilege 15 secret N0rthstar-Admin11!

Creates a local user account for authentication.

ComponentMeaning
username netadminCreates a user named netadmin.
privilege 15Assigns the highest traditional Cisco IOS privilege level.
secretStores a one-way hash of the password instead of plaintext.
N0rthstar-Admin11!Example password for the local account.

Privilege levels: Level 0 offers very limited commands; level 1 is the default user EXEC level; levels 2–14 can be customized; level 15 provides full privileged EXEC access.

secret is generally preferable to password, since it uses a one-way hash. The exact password-hashing algorithm depends on the IOS version and configuration.

Security: Privilege level 15 grants extensive control. For production devices, use a unique strong password, follow an appropriate password-hashing policy, and restrict management access. The password here is a lab example, not a recommended reusable credential.

Command 4: crypto key generate rsa

crypto key generate rsa

Generates an RSA public/private key pair on the Cisco device. SSH can use RSA host keys to authenticate the device and, depending on the negotiated SSH algorithms, support the secure connection process.

On platforms with an interactive prompt, you may see:

How many bits in the modulus [512]: 2048

Use at least 2048-bit RSA keys if supported by your device and IOS version.

2. How the commands work together

Simplified instructional flow. Real SSH also negotiates algorithms and establishes session encryption.

3. Complete example: Enable SSH on a Cisco switch

The original four commands do not by themselves complete SSH remote login. Configure VTY lines, local authentication, and SSH-only transport as well.

enable
configure terminal

! Set device hostname
hostname SW1

! Configure domain name
ip domain-name northstar.com

! Create local administrator account
username netadmin privilege 15 secret N0rthstar-Admin11!

! Generate RSA keys (2048-bit)
crypto key generate rsa modulus 2048

! Prefer SSH version 2
ip ssh version 2

! Configure remote-access lines
line vty 0 15
 login local
 transport input ssh
 exit

end
copy running-config startup-config
Platform note: Some Cisco devices have a different VTY range or RSA key-generation syntax. The switch must also have a reachable management IP address, appropriate interface/VLAN status, and correct routing if the client is on another network.

login local: Authenticates remote users against the device's local username database.

transport input ssh: Allows SSH on the configured VTY lines and disallows Telnet on those lines.

4. Testing SSH

From another machine with network connectivity to the switch's management address:

ssh netadmin@192.168.1.2

192.168.1.2 is an example management IP address. The SSH client may ask you to verify the server's host key fingerprint before prompting for the user's password.

Verify SSH configuration on the Cisco device:

show ip ssh
show crypto key mypubkey rsa
show running-config | section line vty

Key takeaway

The original commands prepare the device for SSH by configuring a domain name, creating an administrator account, and generating RSA keys. line vty, login local, and transport input ssh complete the remote-login configuration.
