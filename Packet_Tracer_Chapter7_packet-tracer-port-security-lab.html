Cisco Packet Tracer Lab: Switch Port Security

Objectives

By the end of this lab, students should be able to:

  • Enable port security on a Cisco switch access port.
  • Limit the number of MAC addresses permitted on a port.
  • Configure a static secure MAC address.
  • Configure sticky MAC learning.
  • Explain the three violation modes:
  • protect
  • restrict
  • shutdown
  • Verify port-security status.
  • Observe what happens when an unauthorized device connects.

Use the following devices:

  • 3 × PCs

2. Configure the PCs

Configure these IPv4 addresses.

Subnet Mask:     255.255.255.0

PC-B

IP Address:      192.168.1.20

No router is required because all devices are in the same subnet.

Part 1 — Verify Normal Switching

From PC-A, ping PC-B:

ping 192.168.1.20

The ping should succeed.

On SW1, examine the MAC address table:

enable
show mac address-table

You should see MAC addresses learned dynamically on Fa0/1 and Fa0/2.

Part 2 — Configure Basic Port Security

Configure Fa0/1 as an access port and enable port security.

enable
configure terminal

interface fastethernet0/1

switchport mode access
switchport port-security

end

Verify:

show port-security interface fastethernet0/1

Students should notice information similar to:

Port Security              : Enabled
Port Status                : Secure-up
Violation Mode             : Shutdown
Maximum MAC Addresses      : 1
Total MAC Addresses        : 0 or 1
Security Violation Count   : 0

Important concept

This command:

switchport port-security

enables the port-security feature.

However, it must normally be used on a Layer 2 access port:

switchport mode access

Part 3 — Configure a Maximum Number of MAC Addresses

Cisco port security normally allows only one secure MAC address by default.

Explicitly configure that limit:

configure terminal

interface fastethernet0/1
switchport port-security maximum 1

end

Verify:

show port-security interface fa0/1

You should see:

Maximum MAC Addresses : 1

This means only one MAC address may use Fa0/1.

Part 4 — Configure Sticky MAC Learning

Instead of manually entering PC-A's MAC address, let the switch learn it automatically.

Configure:

configure terminal

interface fastethernet0/1
switchport port-security mac-address sticky

end

Generate traffic from PC-A.

For example:

ping 192.168.1.20

Now check:

show port-security address

You should see something similar to:

Secure Mac Address   Type                 Ports
------------------   -------------------  -----
00E0.F9XX.XXXX       SecureSticky         Fa0/1

You can also examine the running configuration:

show running-config interface fastethernet0/1

You may see:

interface FastEthernet0/1
 switchport mode access
 switchport port-security
 switchport port-security mac-address sticky
 switchport port-security mac-address sticky 00E0.F9XX.XXXX

What did sticky do?

The command:

switchport port-security mac-address sticky

tells the switch:

Learn the MAC address currently connected to this port and treat it as a secure MAC address.

So the administrator does not have to manually type the device's MAC address.

Part 5 — Cause a Port-Security Violation

Now demonstrate the key feature of the lab.

First, disconnect PC-A from Fa0/1.

Connect PC-C to Fa0/1 instead.

PC-C has a different MAC address.

Generate traffic from PC-C:

ping 192.168.1.20

The switch detects:

Expected MAC address: PC-A
Actual MAC address:   PC-C

Because the maximum allowed secure MAC addresses is:

1

PC-C causes a security violation.

Part 6 — Observe the Default Shutdown Mode

The default port-security violation mode is:

shutdown

Check the interface:

show interfaces status

Fa0/1 may show:

err-disabled

Check port security:

show port-security interface fa0/1

You may see:

Port Security              : Enabled
Port Status                : Secure-shutdown
Violation Mode             : Shutdown
Maximum MAC Addresses      : 1
Security Violation Count   : 1

You can also use:

show interfaces fa0/1

The port will no longer forward normal traffic.

Why Did the Port Shut Down?

The switch was configured to accept only PC-A's MAC address.

When PC-C appeared, the switch detected an unauthorized MAC address.

Conceptually:

Fa0/1
  |
  | Allowed:
  |
  +---- PC-A
        MAC-A
        ✓

Replace PC-A with:

Fa0/1
  |
  +---- PC-C
        MAC-C
        ✗

Different MAC address
        ↓
Port-security violation
        ↓
Violation mode = shutdown
        ↓
Fa0/1 → err-disabled

Part 7 — Recover the Port

Reconnect PC-A to Fa0/1.

Enter:

enable
configure terminal

interface fastethernet0/1
shutdown
no shutdown

end

Check again:

show interfaces status

Fa0/1 should return to an active state.

Then test:

ping 192.168.1.20

Part 8 — Demonstrate Violation Mode: Protect

Now configure:

configure terminal

interface fastethernet0/1
switchport port-security violation protect

end

Verify:

show port-security interface fa0/1

Now replace PC-A with PC-C again and generate traffic.

With protect mode:

Unauthorized frames
        ↓
Dropped

But:

Port stays UP

The switch does not shut the port down.

Part 9 — Demonstrate Violation Mode: Restrict

Reconnect PC-A and configure:

configure terminal

interface fastethernet0/1
switchport port-security violation restrict

end

Replace PC-A with PC-C again.

Generate traffic.

Then examine:

show port-security interface fa0/1

The violation counter should increase.

Conceptually:

Unauthorized MAC
       ↓
Frames dropped
       ↓
Violation counter increases
       ↓
Port remains operational

shutdown

Part 11 — Configure Port Security on Fa0/2

Now configure PC-B's port independently.

configure terminal

interface fastethernet0/2

switchport mode access
switchport port-security
switchport port-security maximum 1
switchport port-security mac-address sticky
switchport port-security violation shutdown

end

Generate traffic:

PC-B → ping 192.168.1.10

Then verify:

show port-security

and:

show port-security address

You should now have secure MAC addresses associated with both ports.

Students should know these commands.

Student Experiment

Have students complete this experiment themselves.

Experiment A

Configure:

switchport port-security maximum 1

Connect one PC.

Result:

1 MAC address
     ↓
Allowed

Experiment B

Replace it with another PC.

Result:

Different MAC
     ↓
Security violation

Experiment C

Repeat the experiment using each of these:

switchport port-security violation protect
switchport port-security violation restrict
switchport port-security violation shutdown

Students should record how the switch behaves differently.

Key Commands to Remember

switchport mode access

Makes the interface a Layer 2 access port.

switchport port-security

Enables port security.

switchport port-security maximum 1

Limits the number of secure MAC addresses.

switchport port-security mac-address sticky

Automatically learns the connected device's MAC address.

switchport port-security violation shutdown

Disables the port when a violation occurs.

show port-security interface fa0/1

Displays detailed port-security status.

The Big Idea

Port security associates a switch access port with one or more authorized MAC addresses:

        Authorized PC
        MAC: AAAA
            |
            v
       +---------+
       | Fa0/1   |
       | Secure  |
       +---------+
            |
       MAC AAAA ✓
       MAC BBBB ✗
       MAC CCCC ✗

It is therefore useful for preventing someone from simply unplugging an authorized endpoint and connecting a different device to the same switch port.
