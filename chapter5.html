Demo 5.1 — Cable Selection and Layer 1 Troubleshooting

Demo time30–35 minutes
Devices2 PCs, 2 switches, 2 routers
Primary focusMedia selection, link state, speed/duplex

Before class

Prepare a table of connection types. Keep the automatic connection tool available but begin with manual cable selection.

Live demonstration procedure

  1. Connect PC-to-switch with copper straight-through. Explain endpoint-to-access-device connections.
  2. Connect switch-to-router with straight-through and switch-to-switch with crossover. Then use Auto-Connect to show that modern interfaces often support auto-MDI/MDIX.
  3. Connect a PC console port to a router console port using the light-blue console cable. Open Terminal and show out-of-band management.
  4. Connect two routers using serial DCE/DTE modules if available. Identify the DCE end and configure clock rate.
  5. Deliberately use an incompatible cable or wrong port. Observe red link indicators and compare with an administratively down interface.
  6. Use show interfaces and show ip interface brief to distinguish physical down/down, administratively down/down, and up/up.
  7. Where supported, set mismatched speed or duplex values and discuss late collisions and poor performance, even if Packet Tracer does not fully simulate real error counters.
  8. Finish with a troubleshooting sequence: power, cable, port, interface state, addressing, then higher-layer configuration.

Command reference

interface s0/0/0
 clock rate 64000
 no shutdown
show controllers serial 0/0/0
show interfaces
show ip interface brief

What students should observe

Students can distinguish media/port compatibility from an IOS shutdown condition. Link lights and interface status provide Layer 1 evidence before any ping test.

Teaching prompts

Ask: “Why is ping not the first test when the link light is red?”

Packet Tracer limitation

Packet Tracer cannot realistically demonstrate attenuation, EMI, crosstalk, optical loss, cable certification, connector polishing, or physical pinouts. Supplement with real cable samples and a tester.
