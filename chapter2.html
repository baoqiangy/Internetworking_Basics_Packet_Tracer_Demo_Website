Demo 2.1 — Build and Document a Small Campus Network

Demo time40–50 minutes
Devices2 routers, 3 switches, 5 endpoints, 1 server
Primary focusLogical/physical diagrams, naming, inventory, change records

Before class

Open Packet Tracer and switch briefly between Logical and Physical workspaces. Prepare a simple campus with Main Building and Annex.

Live demonstration procedure

  1. In Physical view, create or rename containers for a city, campus, Main Building, Annex, and two wiring closets. Explain campus, building, floor, telecommunications room, MDF, and IDF.
  2. Place the core router and server switch in the Main Building MDF. Place one access switch in each building wiring closet.
  3. Return to Logical view and cable the devices. Use labels for WAN/ISP edge, MDF uplink, IDF uplink, and user access links.
  4. Apply a naming convention such as RTR-HQ-01, SW-HQ-MDF-01, SW-ANNEX-IDF-01, and SRV-HQ-WEB-01. Explain why names should encode role and location but not secrets.
  5. Configure management IP addresses on switches and add interface descriptions to router and switch uplinks.
  6. Open the Config tab on several devices and point out serial number/model information available in Packet Tracer. Build an inventory table live using the supplied template in the page.
  7. Deliberately move one PC to a different port. Update the interface description and the documentation table, emphasizing that undocumented change creates future troubleshooting cost.
  8. Save the file as campus-baseline-v1.pkt, make one controlled change, and save as campus-baseline-v2.pkt. Discuss versioning and rollback.

Command reference

hostname SW-HQ-MDF-01
interface g0/1
 description UPLINK_TO_RTR-HQ-01_G0/0
interface f0/10
 description RECEPTION-PC-01
interface vlan 1
 ip address 192.168.10.2 255.255.255.0
 no shutdown
ip default-gateway 192.168.10.1

What students should observe

The logical topology communicates data flow; Physical view communicates location. Device names, labels, descriptions, and versions turn a drawing into operational documentation.

Teaching prompts

Ask: “Which information belongs on the diagram, and which belongs in an asset system?” “What would a technician need at 2:00 a.m.?”
