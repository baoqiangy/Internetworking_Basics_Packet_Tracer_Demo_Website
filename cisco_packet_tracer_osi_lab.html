Lab Overview

You will build a five-device network and use Packet Tracer's Simulation Mode to inspect exactly what happens at each layer as traffic moves across the network.

Topology
PC1 → SW1 → R1 → SW2 → WebServer
Main focus
Data → Segment → Packet → Frame → Bits

Learning Objectives

  • Identify all seven OSI layers and their main functions.
  • Explain encapsulation and de-encapsulation.
  • Distinguish data, segments, packets, frames, and bits.
  • Observe HTTP, TCP, IP, Ethernet, ARP, and ICMP information.
  • Explain why MAC addresses change across routers while end-to-end IP addresses normally remain the same.
  • Compare inbound and outbound PDUs at a router.

14. Key Conclusions

  1. HTTP data starts at the Application layer.
  2. TCP adds port and reliability information to create a segment.
  3. IP adds logical addresses and routing information to create a packet.
  4. Ethernet adds local-link MAC information to create a frame.
  5. Switches primarily forward using Layer 2 MAC addresses.
  6. Routers remove incoming Layer 2 framing, route using Layer 3 information, and build new Layer 2 framing.
  7. MAC addresses normally change across router hops.
  8. Source and destination IP addresses normally remain unchanged during ordinary routing, although fields such as TTL change.
  9. The destination reverses the process through de-encapsulation.
Central idea: Each lower layer wraps control information around the data from the layer above it.
